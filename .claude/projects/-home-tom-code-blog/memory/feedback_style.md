User wants terse, direct responses. No trailing summaries of what was done — they can read the diff.

**Why:** User is hands-on and iterates fast. Lengthy explanations slow things down.

**How to apply:** Lead with action, skip preamble. When user says "push" or "send it", just do it without asking for confirmation. Match their casual tone.
